Scope and Objectives

Scope
The assessment was limited to the intentionally vulnerable Metasploitable 2 virtual machine within an isolated VirtualBox Host-Only network.

Target
- IP Address: 192.168.56.102
- Operating System: Metasploitable 2
- Environment: Local VirtualBox laboratory

Attacker
- Operating System: Kali Linux
- IP Address: 192.168.56.101

Objectives
- Discover the target system.
- Identify exposed network services.
- Enumerate service versions.
- Identify security vulnerabilities.
- Validate selected vulnerabilities in the authorized laboratory.
- Document findings and evidence.
- Recommend appropriate remediation measures.

Out of Scope
No systems outside the isolated laboratory environment were targeted.
