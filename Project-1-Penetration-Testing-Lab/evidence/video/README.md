Video Evidence

This directory contains video evidence demonstrating the penetration testing workflow performed against the intentionally vulnerable Metasploitable virtual machine.

Penetration Testing Demonstration
The demonstration covers the following stages:
1. Network connectivity between Kali Linux and Metasploitable
2. Nmap reconnaissance and service enumeration
3. Identification of the vulnerable vsftpd 2.3.4 service
4. Metasploit exploitation
5. Establishment of a Meterpreter session
6. Verification of root-level access

Lab Environment
Attacker: Kali Linux
Target: Metasploitable 2
Target IP: 192.168.56.102
Attacker IP: 192.168.56.101
Network: VirtualBox Host-Only Network

Purpose
The video provides a continuous demonstration of the penetration testing process and complements the individual screenshots stored in the screenshots directory.
> **Lab Note:** All testing was conducted against an intentionally vulnerable virtual machine in an isolated laboratory environment for educational and authorized security testing purposes.
