Penetration Testing Lab

Overview
This project illustrate a controlled penetration testing and vulnerability assessment lab using Kali Linux and Metasploitable 2.

The objective of the project is to find vulnerabilities, carryout controlled exploitation against an intentionally vulnerable virtual machine, document the findings, and provide recommendations for improving security in real life situation.

Lab Environment

Attacker Machine: Kali Linux
Target Machine: Metasploitable 2
Virtualization Platform: Oracle VirtualBox
Network Type: Host-Only Network
Attacker IP: 192.168.56.101
Target IP: 192.168.56.102

Objectives

1. Perform reconnaissance and network discovery.
2. Identify open ports and running services.
3. Enumerate vulnerable services.
4. Validate selected vulnerabilities in the controlled lab.
5. Document evidence and findings.
6. Provide security recommendations.
7. Produce a professional penetration testing report.

Tools Used for the operation are:

Kali Linux
Nmap
Metasploit Framework
Enum4linux
Netcat
VirtualBox

Project Structure
- `documentation/` — Project methodology, scope and findings
- `scans/` — Nmap and other scan results
* `exploitation/` — Documentation of controlled exploitation activities
- `evidence/` — Screenshots and supporting evidence
- `report/` — Final penetration testing report

Disclaimer

This project was performed in an isolated, intentionally vulnerable laboratory environment for educational and cybersecurity training purposes.
